Chapter 3

Getting started

Launching the app, adding your keyboard as a board, starting your first layout, and saving it.

Launching the app

The app is published as a signed disk image for macOS on the project's GitHub releases page. Open the .dmg, drag Keyboard Curator into Applications and launch it. When a newer release is out, the app offers its page as it starts; Help › Check for Updates… asks at any time, and Help › Check for Updates at Launch turns the automatic check off. The check sends nothing but the request.

You can also run the app from its source code. You need Rust (from rustup.rs) and Apple's Xcode (from the App Store) installed. Then, in Terminal, from the folder that holds the app's source:

cargo run -p kc-app

The first launch compiles the app and takes a few minutes. Later launches start in seconds.

If the build stops with an error about "metal"

The app's graphics need a tool that ships only with the full Xcode app. Either run sudo xcode-select -s /Applications/Xcode.app once, or start the app like this:

DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer cargo run -p kc-app

A layout given on the command line opens straight away, and a keymap file is imported the same way:

cargo run -p kc-app -- "My Go60.kcproj"

My Boards

The app opens on My Boards: a list of your keyboards on the left and, on the right, the one you last looked at, drawn on a plinth with what there is to know about it: model, firmware, current layout and whether it is connected. The first time, the list is empty and the screen asks you to add your first board.

Adding a board

  1. Click Add Board…, or connect the keyboard's main half by USB and click Add Connected Board.
  2. Give the board a Name. The app suggests one; "Go60 at work" or "Travel Imprint" is the idea.
  3. Choose the Model. A connected keyboard has its model chosen for you where its name makes it certain.
  4. Choose the Firmware the keyboard runs, or will run once you flash it. A keyboard cannot report this itself. If you have never flashed anything, it is the manufacturer's: ZMK with Cyboard's module on the Imprint, MoErgo ZMK on the Go60 and Glove80, Dygma firmware on the Defy. You can change it later on the board's page.
  5. Click Add Board. The board's page opens.
Linking

A board can be linked to one physical keyboard by its serial number, so that the app knows which of your boards is plugged in. A keyboard can be linked to only one board at a time; if you link it to another, the app asks first. Link or unlink on the board's page.

Starting a layout

On the board's page, open the Layouts tab and click New Layout. The new layout is not blank. It starts as a complete, working layout modeled on the one your keyboard shipped with: several layers, a system layer with Bluetooth and bootloader keys, and on the MoErgo boards their Magic layer too. This is deliberate. You can change one key, apply, build, flash, and have a keyboard that still does everything you expect apart from that one key.

A board with more than one template to start from shows a menu instead. On the Imprint, New Layout offers the factory layout and TailorKey (by Moosy Research): TailorKey v5.2 Bilateral, Moosy Research's layout for the MoErgo boards, brought to the Imprint with its bilateral home-row mods, autoshift, cursor, symbol, mouse and gaming layers, combos and macros, and its per-layer colors, with the trackballs standing in for the touchpads. TailorKey is described at sites.google.com/view/tailorkey.

The Defy has no factory template yet: its New Layout starts with one empty layer. The better start on a Defy is Read From Keyboard on the Keyboard tab, which opens what the keyboard holds now as a layout (Chapter 13).

A good first layout

Make one small change you will notice, such as swapping two keys, and take it all the way through to the keyboard. Once that loop works for you, bigger changes are just more of the same.

Saving

Press ⌘S to save. The first time, the app asks where; it suggests a Keyboard Curator folder inside Documents. Layouts are single files ending in .kcproj. A saved layout is listed on its board's Layouts tab.

  • The window title shows the layout's name, followed by Edited when there are unsaved changes.
  • ⇧⌘S saves a copy under a new name. This is a simple way to keep versions: "Go60 with home-row mods", "Go60 for gaming".
  • Closing the layout, the window or the app with unsaved changes asks before discarding them.

Layout files are plain text (JSON), with each key on its own line. If you keep them in a version-control tool such as git, changes show up as readable one-line differences. Your boards, with their firmware settings, are kept by the app itself; removing a board forgets its settings but leaves its layout files where they are, and does not change the keyboard.

Undo and redo

Everything you change in a layout can be undone with ⌘Z and redone with ⇧⌘Z: key changes, layer changes, behavior edits, lighting. A painting stroke across many keys counts as one step. Undo history lasts until you close the layout.

Reading the keyboard drawing

Each keycap shows what the key does on the layer you are looking at.

Trackballs and touchpads are drawn as circles and rounded squares between the halves. They are there to orient you; you set them up in Pointing mode. The drawing is a diagram: sculpted keyboards curve in three dimensions and the drawing flattens them, so thumb keys fan out a little differently from the real thing. The order of keys always matches.

Chapter 5

Editing keys

The everyday work: pick a key, pick what it does.

The basic move

  1. In the sidebar, click the layer you want to change.
  2. Click a key on the keyboard drawing. It gets an outline.
  3. Click an entry in the key picker below. The keycap changes at once.

By default the selection then moves to the next key, so you can fill a row by clicking picker entries one after another. The Advance after assigning button above the picker turns this off.

Example: Caps Lock becomes Escape

On the base layer, click the key that currently shows Caps. In the picker's search box type esc, then click Esc. Done. ⌘Z puts it back.

Finding things in the picker

  • Tabs group entries by kind: letters and numbers under Basic, arrows under Navigation, and so on. Chapter 7 goes through every tab.
  • Search looks across every tab at once. It matches names, ZMK's own abbreviations and plain descriptions, in any order. vol finds the volume keys; bluetooth 2 finds the key that selects Bluetooth profile 2; ret finds Enter.
  • Hover over an entry to see a one-line description of what it does, next to the search box.

The picker only offers what your board's firmware can do. If something described in this guide is missing from your picker, the firmware chosen on the board's page does not support it.

The inspector

The panel at the bottom right shows the selected key in detail and offers the most common adjustments.

Binding

The text box shows the key's binding in ZMK's notation, for example &kp A. You can ignore it. But if you know the notation, or are following instructions from the ZMK documentation, you can type any binding here and press Return. Text the app understands becomes a normal, editable binding. Text it does not understand is kept exactly as typed and passed to ZMK as it is.

With modifiers

The four buttons ⌃ ⌥ ⇧ ⌘ add a modifier to what the key sends. They appear for any key that sends a key.

Example: one key for "reopen closed tab"

Assign T to a key, then click ⇧ and ⌘ in the inspector. The keycap reads ⇧⌘T, and pressing the key sends Shift-Command-T.

When held

This row gives a key a second job when you hold it instead of tapping it:

  • None: an ordinary key.
  • ⌃ ⌥ ⇧ ⌘: hold for that modifier, tap for the key. ZMK calls this a mod-tap.
  • A layer's name: hold for that layer, tap for the key. ZMK calls this a layer-tap.
Example: Space that is also a layer key

Select your Space key. Under When held, click your navigation layer's name. Tapping the key still types a space; holding it switches to the navigation layer for as long as you hold.

Once a key has a hold, picking a different key from the picker changes only what a tap sends; the hold stays. These built-in holds use the firmware's default timing. When you want to tune how a hold is told apart from a tap, create your own hold-tap in Behaviors mode (Chapter 8).

Values and Layer

Some bindings carry a number or a layer. For those the inspector shows:

  • Values, with − and + buttons. For example, a "set a specific color" lighting key has hue, saturation and brightness.
  • Layer, with a button per layer, for a key such as "hold for layer…".

A key that uses one of your own behaviors has an Edit Behavior button, which takes you to it in Behaviors mode.

Type to assign

Turn on Type to assign above the picker and the app binds whatever you type on your Mac's keyboard to the selected key, then moves on. It is the quickest way to enter a row of letters. It covers letters, digits, common punctuation, Return, Tab, Space, Escape, Delete and F1 to F12. Turn it off again to get the arrow-key and Delete shortcuts back.

Chapter 6

Layers

Layers are how a small keyboard does everything a big one can, without moving your hands.

How layers behave

The first layer in the list is the base layer. It is always on. Other layers are switched on by keys. When several layers are on, the highest one in the list wins for each key, unless that key is transparent there, in which case the next one down decides.

So a typical layer changes only a handful of keys and leaves the rest transparent. In the drawing, transparent keys show faded, with the legend they inherit.

The five ways to switch layers

All of these are in the picker's Layers tab, one entry for each of your layers.

Picker entryNameWhat it doesGood for
mo + layerMomentaryThe layer is on while you hold the key.Symbols, navigation: anything used in short bursts.
to + layerGo toSwitches to the layer and turns the others off. It stays until another key switches away.A gaming or numpad layer you stay on for a while. Put a "go to Base" key on it.
tog + layerTogglePress once to turn the layer on, again to turn it off.A mouse or numpad layer.
sl + layerStickyThe layer applies to the next key you press, then turns off.One-shot symbols without holding anything.
Inspector: When heldLayer-tapHold for the layer, tap for an ordinary key.Putting layer access on a key you already use, such as Space.
Always leave a way back

If a key takes you to a layer with to or tog, make sure that layer has a key that returns to the base layer. Otherwise you are stuck there until the keyboard restarts.

Managing layers

The sidebar lists your layers with their position number. Under the list, the Selected layer controls act on whichever layer is highlighted.

To do thisDo this

Reordering is safe

In hand-written ZMK files, layer keys refer to layers by number, so moving a layer silently breaks every key that pointed at it. Here, a layer key points at the layer itself. Rename or reorder as much as you like; every layer key keeps working.

Deleting a layer that is in use

If you confirm, keys that switched to the deleted layer are set to do nothing, and any rule, combo restriction or pointing setting that mentioned the layer is removed. One undo brings everything back.

How many layers?

ZMK allows 32 in total. The Spare layers for ZMK Studio counter reserves empty slots that ZMK Studio can later turn into layers without a build; they count toward the 32. If you do not use ZMK Studio, leave it alone. RMK for MoErgo and the Imprint's RMK fork hold 16 layers, and the Defy holds 10; a layout with more is flagged before it is written.

Example: a navigation layer
  1. Click Add Layer and rename the new layer Nav.
  2. On Nav, select the four keys under your right hand's resting position and assign ←, ↓, ↑, → from the Navigation tab.
  3. Switch to the base layer. Select a thumb key. In the picker's Layers tab, click mo Nav.

Hold the thumb key and your right hand has arrow keys. Every other key on Nav is transparent, so it still types what the base layer says.

One entry per layer for each way of switching: mo, to, tog and sl. See Chapter 6.

Mouse

Keys that act as a mouse: left, right and middle click, back and forward buttons, moving the pointer up, down, left or right while held, and scrolling. Useful on a mouse layer beside a trackball or touchpad.

Bluetooth

Your keyboard can remember several computers, phones or tablets. Each remembered device is a profile, numbered from 0.

EntryWhat it does
BT SEL 0 to BT SEL 4Switch to that profile. If the profile is empty, the keyboard becomes discoverable so a new device can pair with it.
BT NXT, BT PRVStep to the next or previous profile.
BT CLRForget the device on the current profile. Use this when a device will not reconnect; then remove the keyboard from that device's Bluetooth list and pair again.
BT CLR ALLForget every paired device.
BT DISC 0 to 4Disconnect a profile without forgetting it.

How many profiles a keyboard has depends on its firmware: five on ZMK and on the Imprint's RMK firmware, three on the Go60 and four on the Glove80 under RMK for MoErgo.

Lighting

Keys that control the keyboard's lights while you use it: on/off, brightness, hue, saturation, effect and effect speed. Chapter 11 explains them.

Keep a bootloader key

If no key in your layout enters the bootloader, you can still flash by using the reset button on the keyboard itself, but it is less convenient. The app warns you when a ZMK layout has no bootloader key. The factory layouts have them on their system layer; leave them there.

Custom

Behaviors you have created yourself in Behaviors mode appear here: your hold-taps, tap-dances, macros and so on. Behaviors defined as text under Custom behaviors in Advanced mode, and those that come with the add-ons built into your firmware, appear here too.
